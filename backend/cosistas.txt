instalar mongoose: npm install mongoose
instalar dotenv: npm install dotenv

instalar todo: npm install mongoose dotenv express cors
instalar nodemon: npm install nodemon --save-dev
luego cambiar en el package.json y añadir lo siguiente (recomiendo porque hace las cosas más faciles, pero creo que ya lo he configurado):
"scripts": {
  "start": "node server.js",
  "dev": "nodemon server.js"
}

Y ya despues se puede ejecutar el servidor en modo desarrollo con npm run dev

para el hasheo de contarseñas npm install bcryptjs

npm install jsonwebtoken  para tener un token de autentificacion que se mandará al frontend
